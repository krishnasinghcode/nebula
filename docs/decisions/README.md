This directory holds Architecture Decision Records (ADRs).

**Do not create an ADR until a significant architectural decision is made.**

## ADR Format

When an ADR is needed, create `NNNN-<short-title>.md` in this directory using:

```markdown
# <NNNN>. <Title>

## Status
Proposed | Accepted | Implemented | Superseded by NNNN

## Context
What problem or force prompted this decision.

## Options Considered
Alternatives evaluated, with trade-offs.

## Decision
What was decided, in one clear statement plus supporting detail.

## Consequences
What this decision enables, costs, and constrains going forward.
```
